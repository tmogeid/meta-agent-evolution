# Trabajos previos y límites de transferencia

## Contexto

Se reconoce la existencia de trabajos previos como contexto de planificación. Este repositorio no importa su código, archivos, dependencias ni historial Git.

## Límite de transferencia

El plan v2 del directorio raíz sigue siendo un borrador ajeno al repositorio. No se modifica ni se agrega al control de versiones de este proyecto.

Las referencias a trabajos anteriores no implican equivalencia técnica, titularidad, licencia ni autorización de reutilización. Cualquier transferencia futura requerirá una decisión explícita y una revisión de procedencia independiente.
