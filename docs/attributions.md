# Atribuciones y procedencia

Este repositorio comienza como un proyecto independiente. No se incorporan código, archivos ni historial de repositorios o trabajos anteriores.

Las atribuciones mencionadas en el contexto de trabajos previos sirven únicamente como referencia de procedencia; no conceden permiso para copiar materiales ni acreditan que estos formen parte del repositorio.

Si una contribución externa se incorpora en el futuro, registrar antes de integrarla su autoría, fuente, licencia y alcance permitido. No incorporar material cuya licencia o procedencia no pueda verificarse.
